# Administration Migration Plan

1. Select and approve the provider architecture.
2. Create additive schemas and migrations in a disposable environment.
3. Import only verified public publication metadata.
4. Compare database reads with file-backed registries.
5. Record parity evidence and backup evidence.
6. Enable founder-only draft administration.
7. Add review records after reviewer appointments.
8. Add pilot and consent records only after legal and ethics review.
9. Migrate Studio operational records only after commercial and IP terms are approved.
10. Retain the file-backed registry until rollback and recovery tests pass.

No destructive migration is authorized by this plan.
