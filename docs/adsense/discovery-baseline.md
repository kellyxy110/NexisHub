# NexisHub AdSense Forensic Discovery Baseline

Audit date: 2026-09-25

Property audited: `https://nexishub.vercel.app`

This is a discovery record, not an approval claim. The audit distinguishes repository evidence, live HTTP evidence, and owner/account evidence that is not available to the repository.

## A. Repository architecture

- Next.js 16 App Router application under `website/`.
- TypeScript, React, Prisma, Auth.js, Vercel deployment, and file-backed editorial registries.
- Public content is primarily statically generated or server-rendered.
- Sitemap is generated by `website/src/app/sitemap.ts`.
- Robots is generated by `website/src/app/robots.ts`.
- No `ads.txt` file, AdSense loader, `ca-pub-` value, or AdSense component was found.
- Cookie controls and optional analytics boundaries exist, but legal review remains pending.
- The contact/newsletter forms are designed around webhook delivery and are not enabled by default.
- Admin, participant, reviewer, consent, and pilot capabilities remain protected or gated.

## C. Sitemap reconciliation

- Supplied/live sitemap count: 84 URLs.
- Blog URLs: 67.
- Research URLs: 7, including the search utility before remediation.
- Static core and legal/product/Studio routes: 17 before the search removal.
- Four distinct `lastmod` values are present: 2026-07-20, 2026-07-23, 2026-07-25, and 2026-08-11.
- The static core routes still use a hard-coded 2026-07-20 date in the generator. This is a P1/P2 freshness-integrity issue, not evidence of current content modification.
- `priority` and `changefreq` are present. They are not treated as a qualification signal.

## D. AdSense and ads.txt status

Current status: `OWNER ACTION REQUIRED` and `NOT PROVEN`.

- No AdSense script is implemented.
- No publisher ID is present.
- `/ads.txt` returns 404.
- No account-level AdSense ownership, site status, review request, or publisher account evidence is available.
- Google’s official guidance requires the account’s actual publisher ID in ads.txt; no value may be invented.

## E. Content baseline

- The live sitemap exposes 67 blog URLs.
- All sampled sitemap URLs returned 200 during the live crawl.
- Blog HTML is substantial in response size, but HTML byte size is not a content-quality measurement because it includes framework payloads and scripts.
- Existing editorial code enforces long-form content for the current guides, but originality, factual accuracy, source quality, and semantic overlap still require human/editorial review.
- High-overlap topic families include AI visibility, machine discovery, structured data, entity clarity, retrieval, citation readiness, and AI search. These are candidates for manual pair review, not automatic deletion.
- Case-study content is methodology-first and should remain so until written client permission and evidence exist.

## F. Trust and claims baseline

- The site identifies NexisHub and names the founder on the About page.
- The homepage and About page display “Trusted by” links for `genshipyard.com` and `truvyx.org`; the repository does not contain independent evidence of the relationship or written permission. Owner verification is required before relying on these as social proof.
- Product registry contains six products, including Pnyx. The homepage count was corrected from five to six.
- SiteNexis and Pnyx are represented as live; other product statuses remain explicit in the registry. Live-product claims require periodic destination verification.
- Legal pages are explicitly marked as drafts for legal review.

## G. Security and protected surfaces

- `/api/` is disallowed in robots, but that is not treated as security.
- Admin routes use server-side session and role checks.
- No private admin URLs are included in the public sitemap.
- No secrets were found in the repository during this baseline review.
- AdSense, consent, publisher, and account settings were not changed.

## H. Initial verdict

`NOT READY TO SUBMIT` at Loop 0.

This is not a prediction of Google’s decision. It reflects the missing ads.txt/publisher evidence, unverified account ownership, pending legal review, unverified consent/advertising implementation, and unresolved content/trust review work.
