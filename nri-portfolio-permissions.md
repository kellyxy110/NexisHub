# NRI and Studio Portfolio Permissions Register

## Status vocabulary

Pending Client Approval, Requested, Approved for Name Only, Approved for Logo, Approved for Screenshots, Approved for Metrics, Approved for Testimonial, Declined, Expired, Withdrawn.

## Client permission request

Organisation, representative, project, requested use, channels, duration, territory, attribution, logo, screenshots, metrics, quotation, withdrawal route, response deadline, and signature.

## Media release

Subject, image or recording description, intended channels, duration, attribution, withdrawal terms, rights holder, consent date, and signature. This is a template and is not a completed release.

## Approval checklist

- [ ] Client identity confirmed
- [ ] Project facts verified
- [ ] Claims separated from opinion
- [ ] Written permission received
- [ ] Permission scope recorded
- [ ] Expiry or withdrawal condition recorded
- [ ] Legal terms checked
- [ ] Publication owner approved

## Current records

Genshipyard, Truvyx, Purple Tech Hub, and CeewhyNews remain Pending Client Approval unless a separate signed record is added. No permission is inferred from a website link, trusted-by display, prior conversation, or working relationship.
