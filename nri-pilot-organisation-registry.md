# NRI AI Visibility Index Pilot Organisation Registry

## Purpose

This registry is a controlled planning sheet for selecting the initial 30-organisation pilot sample. It is not a publication of rankings or findings.

## Sampling target

Select 30 organisations across six sectors, with approximately five organisations per sector where recruitment and eligibility permit.

Suggested sectors:

- software and technology
- education
- healthcare
- professional services
- nonprofit and community organisations
- public or civic information

The final sample must record deviations from this target.

## Registry fields

| Field | Description |
|---|---|
| organisation_id | Stable internal identifier |
| public_name | Public organisation name |
| website_url | Primary public website |
| sector | Controlled sector label |
| region | Public region or country where relevant |
| size_category | Declared or observable study category |
| inclusion_source | How the organisation entered the candidate pool |
| permission_basis | Public source, invitation, consent, or other basis |
| status | Candidate, invited, accepted, excluded, deferred |
| exclusion_reason | Reason for exclusion or deferral |
| contact_owner | Internal study owner, if applicable |
| notes | Non-sensitive study notes |
