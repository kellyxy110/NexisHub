# NRI AI Visibility Index Version 1.0 Release Checklist

- [ ] Research lead named and accepts responsibility
- [ ] Technical, methodology, and ethics or privacy reviewers named
- [ ] Legal review completed where required
- [ ] Pilot organisations accepted in writing
- [ ] Data basis and retention recorded
- [ ] Fixed query set and collection versions frozen
- [ ] Reviewer calibration completed
- [ ] Duplicate review completed
- [ ] Disagreements adjudicated and preserved
- [ ] Missing data and uncertainty analysed
- [ ] Findings separated from interpretation
- [ ] Counterarguments and threats to validity documented
- [ ] Participant corrections processed
- [ ] Publication permissions confirmed
- [ ] References, appendices, glossary, and reproduction instructions complete
- [ ] Version history and review level recorded
- [ ] Final publication approved for release

Until every applicable gate is complete, the public document remains a pre-review working paper and must not be described as a validated index.
