# NexisHub Studio Task Register

## Current status

NexisHub Studio has a working positioning and delivery model in `decision.md`. The Studio service is not yet implemented as a public website surface, sales process, portfolio, or client delivery system.

The NexisHub website and long-form blog remain deployed at `https://nexishub.vercel.app`. Existing NRI work is recorded separately in `decison.md` and `tasks.md`.

## Definition of done for a Studio engagement

- [ ] problem and desired outcome are documented
- [ ] users and stakeholders are identified
- [ ] scope, exclusions, dependencies, and assumptions are approved
- [ ] ownership and confidentiality terms are signed
- [ ] design and accessibility expectations are documented
- [ ] architecture and data decisions are recorded
- [ ] security and privacy risks are reviewed
- [ ] AI features have an evaluation and human-review plan where applicable
- [ ] tests and acceptance criteria are defined
- [ ] deployment and rollback procedures exist
- [ ] documentation and handover are complete
- [ ] client approval and permissions are recorded before public case-study use
